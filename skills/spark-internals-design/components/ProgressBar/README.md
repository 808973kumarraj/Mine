# ProgressBar

Stage progress as a white track filled with green hatching; when a stage stalls, the leading 14px turns to red hatching.

**You provide** `value` (0–1), `caption` (left, muted: "tasks 76 / 200") and `stalled`.

- The percentage on the right is computed for you.
- Pair a stalled bar with a red "STALLED" pill and the figure that explains it.
