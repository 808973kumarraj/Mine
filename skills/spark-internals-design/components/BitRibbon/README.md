# BitRibbon

A record turned into bytes: a blue ribbon of 0s and 1s that waves gently while it travels; `dense` is the compressed form, shorter with tighter bits.

**You provide** `length` and `dense`; `animate` sets it waving.

- Compression is shown as the ribbon shrinking (110 → 56 in EP. 07) with a "LZ4 −52%" pill.
