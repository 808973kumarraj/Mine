# Pipe

The network drawn as a pipe with a narrow throat: in `jammed` mode full-row blocks queue at the throat and glow red; in `flowing` mode small blue and green blocks speed through it.

**You provide** `mode`, `animate`, and optionally `badge` (the flowing readout, default "11× THROUGHPUT") or `readout={false}`.

- Show both, jammed above flowing, with the same pipe: the fix is less data, not a wider pipe.
- The throughput figures in EP. 07 are illustrative; label them so.
