# Stat

One number that carries the scene, in mono 800 with tabular figures, and the line or two that make it mean something.

**You provide** `value`, and optionally `label`, `note` (muted, 8.5px), `detail` (bold, 9px), `tone` (`red` for a cost, `green` for a saving) and `size` (`xl` 34, `lg` 28, `md` 22, `delta` 13).

- Write the real units: "4.7 µs", "48.2 GB", "1.0B → 0.38B". Use "×" for multiply and "≈" for estimates.
- One big number on screen at a time.
