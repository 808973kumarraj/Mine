# CodeCompare

The anti-pattern beside the fix: two cards, "ANTI-PATTERN" in red and struck through with a thick red-on-ink slash, "DO THIS" in green.

**You provide** `bad` and `good`, each `{ title, code: [lines], note }`; `struck={false}` drops the slash.

- Two lines of code per side, aligned so the difference is visible. The note says why in four words or fewer.
- The slash is drawn over the bad card only. The words ANTI-PATTERN and DO THIS carry the meaning without color.
