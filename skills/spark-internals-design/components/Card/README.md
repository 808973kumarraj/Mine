# Card

A raised sheet of `paper` with a 1.2px ink outline, 8px corners and a soft shadow, for figures that need their own frame: the stage readout, the cost card, the per-record toll.

**You provide** `children` and usually an `eyebrow` (uppercase muted 8.5px); `tone` colors the eyebrow `red` or `green` for verdicts.

- 14px padding. One card per idea; never nest cards.
- The eyebrow names what the card measures, in the system's own words: "COST PER RECORD", "PER-RECORD TOLL".
