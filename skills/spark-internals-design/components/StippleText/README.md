# StippleText

Text that prints itself: each character arrives as a scatter of dots on a 3 × 4 grid, then resolves, left to right.

**You provide** `text`, `family` (`mono` or `serif`), `size`, `weight`, `color` (a token name) and `animate`.

- Use it for scene titles and the end card's title, never for running text.
- A title reveals in about 1.1 s; the end card's in 1.4 s.
- Under reduced motion the text appears whole.
