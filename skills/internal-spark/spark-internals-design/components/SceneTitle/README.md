# SceneTitle

The label at the top-left of every scene: number, em dash, name ("05 — COST PIPELINE") in muted 10.5px bold, over a 180px dashed rule.

**You provide** `n` and `name` (set uppercase for you); `animate` replays the stipple reveal.

- In an episode, draw it with `K.title(n, NAME, t)` at x 20, y 68 so it reveals over the first 1.1 s.
- Muted on cream is 4.4:1, the episode's own pairing. Keep the name short.
