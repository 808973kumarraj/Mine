# Pill

A short state or verdict in a capsule: uppercase mono 8.5px bold, 17px tall, half-height corners, a soft drop shadow.

**You provide** the words as `children`, a `tone` and optionally `size` (`key` 15px, `sm` 15px for long labels, `lg` 21px for the end card) and `dot` (an LED inside a green pill).

- Tones carry meaning: `red` stalled or costly, `green` done or healthy, `blue` an operation on data, `amber` broadcast and "now", `ink` neutral counts, `outline` a label placed on a diagram. `k1`–`k4` name partition keys and stay lowercase.
- Write the label in capitals with "·" between facts: "BROADCAST · 4 COPIES · 48 MB".
- Amber pills take ink text (5.4:1). The episode set one in cream (2.8:1); don't copy that.
- One or two pills per scene. A pill with a word never relies on its color alone.
