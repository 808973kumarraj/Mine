# Terminal

The one line of code that sets the scene in motion: an ink bar with an amber "›" prompt, cream code, light green strings and a blinking amber block cursor.

**You provide** `command`; `typed` (0–1) shows it mid-typing; `cursor={false}` hides the cursor.

- Real, runnable code in the system's language (PySpark or Scala), one line.
- In an episode it types out over about 1.3–1.6 s with `K.terminal`.
