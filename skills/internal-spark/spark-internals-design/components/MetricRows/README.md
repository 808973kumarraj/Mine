# MetricRows

Label and value pairs down a card, label in muted lowercase on the left, value bold on the right, a `hairline` under each row.

**You provide** `rows`: `{ label, value, tone }`, where `tone` is `red` for a figure that is going wrong.

- Labels stay lowercase ("spill to disk"); values carry units.
- Three to five rows. Rows sit 17px apart.
