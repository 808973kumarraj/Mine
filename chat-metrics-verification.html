How to reproduce

Row hash = SHA-256 of the row's fields as compact JSON (UTF-8). Manifest root = each row hash folded into the previous link, so changing, removing or reordering any row changes the root. Store match compares session id, message, start time, model, output tokens, total tokens and tool calls with the live session store.
Scope. This report shows that the dataset is internally consistent, identical to what is committed in git, and agrees with the session store on the machine where it ran. 5 of the 16 recorded turns are errors that never reached a model. The hashes are unsigned and the timestamp comes from the host clock, so they detect later changes to the files but are not independent third-party attestation.
