Source of truth

The table is whatever the log says it is. Parquet files with no add action are invisible to readers.

Atomic commit

A commit is one put-if-absent of N.json. On S3 this needs a coordinator (DynamoDB LogStore or S3 conditional writes).

Spark classes

DeltaLog → SnapshotManagement.update() → LogSegment → Snapshot → OptimisticTransaction.commit().

Checkpoints

Every delta.checkpointInterval commits (default 10). _last_checkpoint points at the latest so readers skip listing.
