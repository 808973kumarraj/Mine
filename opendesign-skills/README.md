# OpenDesign skills for Claude

169 skills from [nexu-io/open-design](https://github.com/nexu-io/open-design) (Apache 2.0), packaged for upload to claude.ai.

- `zips/<skill>.zip`: one skill per zip, ready to upload.
- `all-opendesign-skills.zip`: every skill zip in one download.

Upload: claude.ai → Settings → Capabilities → Skills → Upload skill (one zip at a time). Uploaded skills also work in the Claude mobile app.
